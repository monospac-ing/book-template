Newsreader — web subset
=======================

Newsreader by Production Type (https://github.com/productiontype/Newsreader),
from the Google Fonts repository (ofl/newsreader), released under the SIL Open
Font License 1.1 (see OFL.txt). Newsreader declares no Reserved Font Name.

2026-11-21 (monospac-ing)
- Subset the variable fonts (weight 200–800, optical size 6–72, roman and
  italic) to Latin: Basic, Latin-1, Extended-A and common punctuation,
  keeping all OpenType layout features. Converted to WOFF2. No other changes.
