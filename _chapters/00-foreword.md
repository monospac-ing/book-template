This is a template for publishing a book-length text as a website: a cover, a table of contents, and one page for each part, read in order. Every page you are reading is a plain Markdown file in the `_chapters` folder. Replace these words with your own and the site rebuilds itself.

The design takes its cues from the printed book rather than the web feed. There is a running head at the top of each page, a folio that tells you where you are, and a page turn at the bottom. On a keyboard, the left and right arrow keys move between parts.

Nothing here needs a build tool on your computer. GitHub Pages turns the Markdown into pages each time you save a change. The fonts are open source and live inside the repository, so the site does not depend on any outside service.

Read on for how each piece works.
