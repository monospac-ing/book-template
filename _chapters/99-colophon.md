Set in Common Serif, designed by Stefan Peev as part of the Localfonts project and built on Libertinus Serif. It is released under the SIL Open Font License; the license and the font's log are in `assets/fonts`.

Built with Jekyll and published with GitHub Pages. Images are dithered to one bit with `tools/dither.py`.
