Set in Monospacing Serif, a variable version of Common Serif, designed by Stefan Peev as part of the Localfonts project and built on Libertinus Serif. The Sans view, switched in the header, is set in Common Sans, also by Stefan Peev. All are released under the SIL Open Font License. The licenses and logs of the changes made for these web versions are in `assets/fonts`.

Built with Jekyll and published with GitHub Pages. Images are dithered to one bit with `tools/dither.py`.
