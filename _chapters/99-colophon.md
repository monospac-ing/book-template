Set in Common Revised, a variable version of Common Serif, designed by Stefan Peev as part of the Localfonts project and built on Libertinus Serif. Both are released under the SIL Open Font License. The license and a log of the changes made for this version are in `assets/fonts`.

Built with Jekyll and published with GitHub Pages. Images are dithered to one bit with `tools/dither.py`.
