Set in Archivo, designed by Omnibus-Type, and EB Garamond, a revival of Claude Garamont's types by Georg Duffner and Octavio Pardo. Both are released under the SIL Open Font License; the license files are in `assets/fonts`.

Built with Jekyll and published with GitHub Pages. Images are dithered to one bit with `tools/dither.py`.
